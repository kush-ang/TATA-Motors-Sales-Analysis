# TATA-Motors-Sales-Analysis
# 🚗 TATA Motors Sales Intelligence Dashboard

## 📌 Project Overview
A comprehensive Full Stack Data Analysis project built on TATA Motors 
sales data containing 250,000+ records across 7 countries, 6 regions, 
and 10 years (2015-2024). This project demonstrates end-to-end data 
analysis skills using industry-standard tools.

## 🛠️ Tools & Technologies
| Tool | Purpose |
| Python (Pandas, Matplotlib, Seaborn) | Data Cleaning & Exploratory Data Analysis |
| MySQL | Business Query Analysis |
| Power BI | Interactive Executive Dashboard |
| Streamlit | Live Interactive Web Application |

## 📊 Dataset Information
- **Total Records:** 250,000+
- **Columns:** 34
- **Years:** 2015 - 2024
- **Countries:** India, USA, UK, Germany, France, Japan, Australia
- **Regions:** North, South, East, West, Northeast, Central

## 🔄 Project Workflow

### 1️⃣ Data Cleaning (Python)
- Handled 62,000+ null values in promotion and previous_car_brand columns
- Standardized text casing across all categorical columns
- Fixed data type inconsistencies
- Exported cleaned dataset with zero null values

### 2️⃣ Exploratory Data Analysis (Python)
- Year-wise Revenue Trend Analysis
- Top 5 Car Models by Units Sold
- Region-wise Revenue Distribution
- Test Drive vs Sales Conversion Analysis
- Age Group vs Income Group Heatmap
- Competitor Conquest Analysis
- Discount Leakage Investigation
- Delivery Time vs Customer Rating

### 3️⃣ SQL Analysis (MySQL)
- Top Countries by Average Sale Price
- Discount Leakage by Reason
- First Time Buyer % by Region
- Sales Channel Performance Comparison
- Year-over-Year Growth Rate using Window Functions (LAG)

### 4️⃣ Power BI Dashboard (5 Pages)
- **Home** — Navigation Page
- **Executive Summary** — KPI Cards, Revenue Trends
- **Sales & Revenue** — Regional & Country Analysis
- **Customer Insights** — Demographics & Behavior
- **Operations & Discount** — Leakage & Delivery Analysis

### 5️⃣ Streamlit Web App
- Interactive filters for Year, Region, Country
- Live Revenue Analysis
- Customer Insights
- Competitor Conquest Analysis
